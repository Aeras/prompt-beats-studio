## Συνολική τοπική υλοποίηση και περιορισμοί

Η νέα διαδρομή ενεργοποιείται μόνο στη V2 και μόνο με τη νέα συναίνεση `football-v2-full-evidence-1`. Το πραγματικό server handler δίνει στην AI το πλήρες cleaned κείμενο που επέστρεψε ο πάροχος ή ρητά επισημασμένο snippet. Δεν εγγυόμαστε πλήρες άρθρο: η πληρότητα του παρόχου παραμένει unknown. Οι μη ασφαλείς σύνδεσμοι διατηρούνται ως ανώνυμες απορρίψεις, όχι clickable URLs. Ίδιο URL με διαφορετικό κείμενο διαβάζεται χωριστά και απαιτεί συγκεκριμένη παραπομπή στην έκδοση· ακριβές διπλότυπο δεν διαβάζεται δεύτερη φορά. Οι παραπομπές της τελικής εκτίμησης εμφανίζονται μία φορά ανά URL.

- **Ένα ή έως πέντε μοντελικά αιτήματα:** μία ανάγνωση/σύνθεση όταν χωράει· αλλιώς έως τέσσερις εξαγωγές και μία σύνθεση. Κάθε extraction δέχεται πραγματικό κείμενο και manifest προέλευσης, όχι προεπιλεγμένες parser claims. Η τελική staged σύνθεση δέχεται ελεγμένη εξαγωγή, όχι ολόκληρα άρθρα. Το μήκος κάθε πραγματικού payload και το SHA-256 καταγράφονται πριν από dispatch. Οι extraction boundaries δεν τεκμηριώνουν από μόνες τους recall μιας πρότασης που διασχίζει όριο chunk.
- **Κόστος:** δύο αναζητήσεις όπως πριν, εκτίμηση 2 Basic / 4 Advanced credits βάσει της υφιστάμενης τιμολόγησης της εφαρμογής, όχι νέα επιβεβαίωση invoice. Upfront model allowance έως 1.331.200 συντηρητικά input tokens και 49.152 output tokens συνολικά. Η μετατροπή bytes σε token upper bound περιλαμβάνει 4.096 framing ανά αίτημα και δεν είναι ακριβής tokenizer μέτρηση. Δολάρια υπολογίζονται μόνο από αποθηκευμένες διαχειριστικές τιμές· άγνωστη τιμή μένει null. Πραγματικά tokens/κόστος αποθηκεύονται ανά tracked execution και στη bounded αναφορά, χωρίς αυτόματο retry ή επιπλέον Tavily/Extract.
- **Χωρητικότητα εγκατεστημένου μοντέλου:** απαιτούνται επιβεβαιωμένα `ai_models.context_window` και `max_output_tokens >= 16384`. Το σημερινό install path αποθηκεύει context αλλά δεν εγγυάται max_output_tokens. Δεν έγινε παραγωγική ανάγνωση ή συμπλήρωση τιμών. Εάν λείπουν, η V2 αναφέρει incomplete coverage πριν από AI dispatch· οι αναζητήσεις μπορεί ήδη να έχουν ολοκληρωθεί. Η επιχειρησιακή ενεργοποίηση απαιτεί έλεγχο και, αν χρειάζεται, χωριστά εγκεκριμένη ενημέρωση registry από αξιόπιστα στοιχεία. Δεν εικάζουμε όρια ούτε αλλάζουμε το καθολικό model registry σε αυτή την εργασία.
- **Χρόνος:** διατηρούνται 150s συνολικά/90s ανά μοντελικό αίτημα. Δεν εγγυόμαστε ότι πέντε πραγματικές κλήσεις ολοκληρώνονται μέσα σε αυτά. Deadline, ανάκληση πρόσβασης, αβέβαιη έκβαση, αποτυχία journal/schema/τελικής αποθήκευσης ή capacity overflow παράγουν ατελή κάλυψη, χωρίς εφαρμοσμένη τελική εκτίμηση. Δεν υπάρχει αυτόματη επανεκτέλεση/συνέχιση αβέβαιου πληρωμένου σταδίου.
- **Αναγνώριση και ανεξαρτησία:** άγνωστοι εκδότες και οποιαδήποτε περιγραφική αγορά διαβάζονται. Η literal quote validation γίνεται μετά την AI ανάγνωση. Οι αυστηρές ψήφοι απαιτούν και αναγνωρισμένη συντακτική στάση/market semantics και γνωστή ανεξάρτητη προέλευση. Μη αναγνωρισμένη φυσική διατύπωση παραμένει provisional, δεν εξαφανίζεται από την ανάγνωση ούτε βαφτίζεται έγκυρη ψήφος. Καμία μετρημένη επίδοση discovery/precision/recall σε πραγματικό corpus δεν προκύπτει από τα synthetic tests. Ο έλεγχος αντιγραφής είναι συντηρητικό fingerprint/attribution/reviewed-family MVP, όχι πλήρης ανίχνευση παράφρασης ή διαγλωσσικής αναδημοσίευσης.
- **Ιστορικό και ασφάλεια:** bounded source sidecar και usage report, χωρίς raw άρθρα, prompt bodies ή μυστικά στη βάση/εξαγωγή. Μέχρι 80 σύντομα ακριβή quotes. Owner/fixture/cutoff validation στην ανάκτηση· παλιό V1 JSON δεν ξαναγράφεται. Τα token/cost receipts των ανεξάρτητων stages παραμένουν στους υφιστάμενους service-only tracked executions. Δεν χρειάζεται νέα SQL migration. Rollback εφαρμογής με ανέπαφα immutable snapshots, όχι αντιστροφή δεδομένων. Η προηγούμενη εφαρμογή μπορεί να εμφανίσει το legacy main assessment, χωρίς τη νέα πλήρη καρτέλα.

### Αποδεικτικά offline acceptance

Τα fixtures είναι ρητά συνθετικά, με πραγματικό adapter και πραγματικό handler, εικονικές HTTP/model υπηρεσίες και μηδενικό κόστος. Στο A/B fixture η παλιά προβολή 650 χαρακτήρων χάνει σαφή late authored pick, ενώ το πραγματικό νέο model payload περιέχει το αυτούσιο κείμενο και η επιστροφή δένεται στο σωστό quote/URL. Δεν αποτελεί πραγματικό benchmark Luna.

Ο handler ελέγχεται με 20 πηγές, δύο πραγματικά mocked Tavily calls, structured provider inputs, μία σύνθεση ή τέσσερις συνολικές model calls στη staged περίπτωση και δέκα διαδοχικές αναλύσεις χωρίς πληρωμένα retries. Μικτή mobile fixture: 5 returned records (raw, snippet, duplicate, unsafe), 3 συντακτικές υποψήφιες επιλογές, 2 ανεξάρτητοι εκδότες, 2 πραγματικές τελικές παραπομπές. Τα τρία source disclosures διαχωρίζονται και το incomplete history χωρίς analysis εμφανίζεται καθαρά.

Η διάγνωση παραγωγής παραμένει **NOT_VERIFIED**: δεν ανακτήθηκε το ιδιωτικό production receipt, δεν εκτελέστηκε νέα live αναζήτηση ή AI. Απαιτείται χωριστή έγκριση για push/Draft PR/τρία ακριβούς HEAD CI gates, ανεξάρτητη αξιολόγηση και merge· publish, registry update και live smoke είναι ξεχωριστά release βήματα. Το merge δεν ισοδυναμεί με publish.
