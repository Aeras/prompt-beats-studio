### Υλοποίηση

- Νέο προαιρετικό `onlineEvidenceV2`, strict/versioned, δίπλα στο υπάρχον V1. Το V1 builder, τα 14 quoted markets, τα odds και τα ιστορικά JSON δεν ξαναγράφονται. Το model δεν μπορεί να επιστρέψει authoritative V2 metadata: αφαιρούνται όλα τα echoes πριν από validation και προσαρτάται το server-owned αποτέλεσμα.
- Opt-in Football adapter έως 24.000 χαρακτήρες ανά source με cleaned/retained/truncated metadata. Ακριβές Music default 4k/text/3 results διατηρείται. Fixed Tavily origin, manual redirects, συνολικό ceiling 4 MiB, ένα timeout/signal, αυστηρό UTF-8 μόνο στο Football opt-in, ασφαλής διακοπή stalled fetch/reader, χωρίς retry. Όχι arbitrary URL fetch ή extract endpoint.
- Canonical representation `football-clean-v2`: CRLF/CR → LF, αφαίρεση NUL. SHA-256 στο ίδιο bounded κείμενο, UTF-16 offsets, σύντομα ακριβή windows και πλήρη literal quotes μέσα στα όρια. Header και γειτονικό pick context, όχι τυφλό Football prefix. Markdown headings ορίζουν χωριστό scope· unscope multi-fixture σελίδες δεν μετρούν. Δεν αποθηκεύονται πλήρη raw άρθρα στην εφαρμογή.
- Trace όλων των predicates, όχι short-circuit: δύο clubs/aliases, κατεύθυνση έδρας και Away at Home, ημερομηνία/έτος, competition/edition, women/youth/reserves, πολλαπλά fixtures, explicit ώρα/conflict, cutoff. Date-only σύνδεση επιτρέπεται με συγκεκριμένη εγχώρια timezone και χωρίς contradiction. Η ώρα δεν απαιτείται, αλλά δηλωμένη kickoff χωρίς zone συγκρίνεται με τη venue-local ώρα. Γνωστά μη ασφαλή island-zone fallbacks και μη καθορισμένο διεθνές venue μένουν provisional. Δεν εφαρμόζεται ανοχή ±1 ημέρας/36 ωρών. Explicit publication rows δεν βαφτίζονται kickoff.
- Ξεχωριστό descriptive AST: FT/HT 1X2, DC, exact half-line totals, BTTS, HT/FT, explicit correct score, έως δύο AND legs και unmapped. Χ/2 ≠ Χ2, П2, ТБ/ТМ, ΟΖ/GG/NG. Integer/Asian settlement που δεν τεκμηριώνεται παραμένει unmapped. Συνήθεις authored sentences χωρίς colon υποστηρίζονται· δεν υπόσχεται general-purpose NLP recall. Negation/conditional/odds-only/attribution/injection δεν γίνονται votes. Δύο picks δεν γίνονται αυτόματα combo, combo δεν δίνει child votes, Over 3.5 δεν δίνει ψήφο Over 2.5.
- Bounded ledger πριν από dedupe: πηγή, literal quote, AST, stance, section/quote offsets, trace, eligibility και λόγοι. Known publisher families επαναχρησιμοποιούνται. Unknown/community/attributed/copies παραμένουν ορατά χωρίς strict ψήφο. Exact και bounded near-copy reasoning, όχι αυτόματη αναγνώριση κάθε cross-language μετάφρασης. Αντιφάσεις της ίδιας προέλευσης αφαιρούνται από τον comparable denominator. DC overlaps δεν χαρακτηρίζονται αυτόματα αμοιβαία αποκλειόμενα.
- Η μοναδική υπάρχουσα σύνθεση λαμβάνει server-validated V2 summary έως 8.000 JSON χαρακτήρες επιπλέον. Επιλογή ολόκληρων claims/groups και ρητοί omitted counters, όχι truncation μέσα σε quote. Η AI κρίση μένει χωριστή από votes. Δεν επινοούνται odds, joint probability ή +EV. Νέα, σωστά συνδεδεμένα V2 URLs μπορούν να τεκμηριώσουν την υπάρχουσα χωριστή AI κρίση.
- Compact EL/EN panel πριν από τον ίδιο Expert, με markets/periods, countable/provisional, query wording language έναντι detected script, source URLs, publication/access dates, quotes και αιτίες. Η ανίχνευση script δεν παρουσιάζεται ως επαληθευμένη γλώσσα πλήρους άρθρου. Κανένα history expand δεν εκκινεί έρευνα. Expert prompt/payload/consent/usage παραμένουν ίδια.

### Πλάνα αναζήτησης και οικονομικό όριο

Το production profile παραμένει **legacy-3**: οι δύο παλιές facts/news queries και η ίδια μικτή forecast query. Καμία πρόσθετη αναζήτηση, αλλαγή depth/model ή automatic fallback. Αποθηκεύονται τα actual queries. Ο ordinal intent εξακολουθεί να δηλώνει τι ζητήθηκε, ενώ η ανίχνευση claims δεν περιορίζεται στην τρίτη query.

Το `planFootballForecasts()` είναι offline-only και δεν συνδέεται με paid dispatch/input/UI selector. Παράγει ουδέτερα EL/EN/RU queries με πραγματική local date, εγκεκριμένο ελληνικό label και Latin fallback όπου δεν υπάρχει reviewed ρωσικό alias. Για το fixture του περιστατικού:

- EL: `Φιορεντίνα Γιουβέντους 8 Νοεμβρίου 2026 προγνωστικά αγώνα`
- EN: `Fiorentina vs Juventus 8 November 2026 match prediction preview` (με το canonical registry spelling όπου διαφέρει)
- RU: `Fiorentina Juventus 8 ноября 2026 прогноз на матч` (Latin fallback, όχι επινοημένη μεταγραφή)

P0: 3 forecasts, web facts μειώνονται· P1-Lean: 3+1 consolidated, επάρκεια μη μετρημένη· P1-Preserve: 3+2 legacy facts/news, δύο επιπλέον searches. Και τα τρία είναι **disabled για paid dispatch**, χωρίς επιλογή από forged request. Τα 3/5/7 results και text/markdown υπάρχουν ως bounded adapter options για offline/χωριστά εγκεκριμένο A/B· το runtime παραμένει text/3. Country, extract και ξεχωριστό LLM extraction δεν ενεργοποιούνται.

Hard call envelope: **3 σειριακές Tavily calls × max 3 documents και 1 υπάρχουσα synthesis call**, χωρίς retry. Η συνήθης εκτίμηση είναι 3 Basic ή 6 Advanced credits, όχι νέο τιμολόγιο/εγγύηση provider. Το V2 επεξεργάζεται περισσότερο raw κείμενο τοπικά και προσθέτει έως 8k JSON chars στο υπάρχον prompt: τα input tokens/κόστος μπορούν να αυξηθούν. Δεν δηλώνεται σταθερό USD ceiling ή hard cap τελικής AI εξόδου, επειδή το ήδη υπάρχον call παραλείπει maxTokens και εφαρμόζει τις τιμές του εγκατεστημένου μοντέλου. Πραγματικό κόστος/latency δεν μετρήθηκε χωρίς paid calls. Δεν υπάρχει υπόσχεση 5–7 επιλέξιμων ανεξάρτητων πηγών.

### Απόφαση συμβατότητας αποθήκευσης μετά τον τελικό έλεγχο

Το V2 στο API παραμένει optional `analysis.onlineEvidenceV2`, αλλά **δεν αποθηκεύεται ως νέο top-level field του strict V1 analysis στη βάση**. Το παλιό schema δεν θα το αγνοούσε: θα απέρριπτε όλη την ανάλυση σε rollback. Γι’ αυτό η ίδια atomic completion update γράφει ακριβώς το V1 analysis και προσθέτει ένα URI-less, versioned `football-online-evidence` sidecar στο υπάρχον `sources` JSON array. Οι παλιοί source readers το απορρίπτουν μέσω του υπάρχοντος φίλτρου URL, ο παλιός Expert συνεχίζει να διαβάζει το ίδιο strict analysis, ενώ ο νέος history reader το επικυρώνει χωριστά και το προσθέτει μόνο στην API προβολή. Fixture identity και cutoff πρέπει να συμφωνούν ακριβώς· duplicate/malformed/wrong-fixture sidecars δεν ενυδατώνονται και δεν εξαφανίζουν το V1 αποτέλεσμα. Δεν επανεγγράφεται καμία παλιά εγγραφή. Automated tests ελέγχουν τον πραγματικό completion payload με strict schema χωρίς V2, τη χωριστή ανάκτηση, τα όρια και την αποτυχία binding. Οι αρχικές αστοχίες αυτού του regression test αποκάλυψαν missing import στο test harness και έλλειψη fixture envelope στο πρώτο τοπικό V2 draft· διορθώθηκαν πριν από την παράδοση, χωρίς χαλάρωση assertions.

Ο τελικός έλεγχος πρόσθεσε επίσης προστασία για odds/history/injection context σε προηγούμενη γραμμή, όχι μόνο μέσα στο ίδιο literal quote, και για νέα citation URLs με future publication/access time. Η επιλεξιμότητα citation δεν συγχέεται με τη σύνδεση του match section ή με την ανεξαρτησία origin.
